# Minesweeper în Python

Implementare clasică a jocului Minesweeper realizată în Python folosind biblioteca grafică `tkinter`.

## Cum se rulează
Asigură-te că ai Python 3 instalat, apoi rulează:
\`\`\`bash
python minesweeper.py
\`\`\`

## Controale
* **Click Stânga:** Sapă / descoperă celula
* **Click Dreapta:** Plasează sau scoate un steguleț
